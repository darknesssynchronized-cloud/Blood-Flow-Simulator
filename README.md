# Blood Flow Simulator (Biomedical Hemodynamics Laboratory)

Interactive educational tool for Biomedical Engineering students demonstrating the Hagen–Poiseuille Law ($Q \propto r^4$).

## Features
- Real-time HTML5 Canvas Red Blood Cell (RBC) flow simulation with parabolic velocity profiles
- Physical RBC size preservation during vessel radius scaling
- Live hemodynamic metrics (Flow Rate, Reynolds Number, Shear Stress, Resistance)
- Interactive Radius vs. Flow Rate chart
